Done (history; no longer tracked here)
================================================
v0.1.2: unit tests wired into CI; ReShade .ini compatibility; profile dropdown
removed; overlay resizing/dragging polish; titlebar icon; RC1 audit.
v0.1.3: RAII owners for raw allocations and C resources; std::optional lookups in
EffectRegistry; Vulkan handle ownership via per-device serial-keyed RetireQueue
(no process-global destroy queue); the ghost "MXAO" effect entry (the preset model
drops effect-list entries that name no instance); monolith split (vkhook.cc and
imgui_overlay.cc no longer exist; layer/, present/, depth/, control/, overlay/);
the global audit (AGENTS.md catalog C1-C8, H1-H26, mostly S1/S2).

vkQueueSubmit2, no layer objects in game command buffers, one resolve shader),
EffectId (every technique runs), per-device registry/config, compile worker,
ping-pong chain images, vkhook_core static library, pinned shader corpus, pixel
readback test, per-architecture-safe layer manifest, one VERSION source.
All AGENTS.md catalog items C1-C8 and H1-H26 are closed.
Dropped: porting built-in effects to .fx (the built-ins stay in
assets/builtInShaders); tools/test-shaders.cc; hosted CI (checks run locally,
see docs/WORKFLOWS.md).
KeyUniform: sources "key", "mousebutton", "mousepoint", "mousedelta" are not
implemented; they read back as zeros and the parser reports the zeroed sources
(effects/reshade_uniforms.cc), so an effect no longer fails silently.

Next: correctness and architecture
================================================
1. Invariant 13 remainder: DLSS5 ModelCache and the shader cache are process-wide
   (keyed by device, documented); Wayland-interpose statics; the Wayland key
   withhold is process-wide.
2. Unify createRenderPass and createEffectRenderPass (different layouts, load ops,
   dependencies).
3. Mixed per-aspect depth/stencil layouts, vkCmdWaitEvents layout changes and
   in-pass vkCmdClearAttachments are not tracked by the DepthTracker.
