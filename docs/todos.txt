Next: correctness and architecture (AGENTS.md catalog, still open)
================================================
1. C4  Stop recording layer pipelines/descriptor sets/render passes into the game's
   command buffers (depth snapshot): transfer-only copies into layer storage, or
   ONE_TIME_SUBMIT only, with reset/free/pool-destroy tracking.
2. H9/H10/H11  Depth: no vkCmdResolveImage on depth, separateDepthStencilLayouts for
   DEPTH_READ_ONLY, both aspects in barriers, a vkQueueSubmit2 hook, barrier-tracked
   layouts (DepthTracker rewrite).
3. H14  Run every technique of a .fx file, not just techniques[0] (dh_uber_mask,
   DH_UI_TextDetect need independently ordered BEFORE/AFTER techniques).
4. H21  VRAM: imageCount x (maxEffects+1) full-resolution images and the silent
   drop of effects beyond the cap; pool and alias intermediates.
5. H2  Compile effects on a worker thread, swap at present (today compiles run on the
   present thread without a lock held).
6. Invariant 13: remaining process-global mutable state (baseConfig, config,
   effectRegistry, cachedEffects, activeProfile*, DLSS5 ModelCache, shader cache,
   Wayland-interpose statics). Make them per-device/per-swapchain or LayerContext.
7. Unify createRenderPass and createEffectRenderPass (different layouts, load ops,
   dependencies).
8. Syncobj gate for a mixed faked/passthrough present uses only the first
   swapchain's InputSession; ensurePersistentDepthStorage allocates under stateLock
   in the submit hook.
